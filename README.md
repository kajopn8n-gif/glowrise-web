# glowrise-web

The public pages for the **Glow Rise** iPhone app: privacy policy, terms and
support. Served by GitHub Pages at
<https://kajopn8n-gif.github.io/glowrise-web/>.

Nothing here is edited by hand. The wording lives in the app, in
`src/legal/documents.ts`, and these pages are generated from it with
`node scripts/build-legal-site.cjs` so the app and the website can never
disagree.
